Ketika halaman form_data_diri.html dibuka, userr dapat mengisi nama lengkap, tanggal lahir, dan memilih hobi yang diinginkan. setelah tombol kirim ditekan,
data yang telah diisi akan dikirim ke file proses_data_diri.php menggunakan metode post. selanjutnya, php akan mengambil dan mengolah data tersebut, 
seperti mengubah format tanggal menjadi nama bulan serta menggabungkan hobi yang dipilih menggunakan koma dan spasi. setelah semua data selesai diproses, 
hasilnya akan ditampilkan pada halaman tampilan data, sehingga data diri yang sebelumnya dimasukkan dapat dilihat Kembali,
